### Environment trap (L-05, and worse here)

`cz_preflight` runs a bare `pytest`. This sandbox has **no pytest on PATH at all** —
the interpreter at `/usr/local/bin/python` has neither pytest nor ruff. A venv was
built at `./venv` (gitignored) and every check in this plan was run through
`./venv/bin/python -m pytest`. Expect `cz_preflight`'s test check to fail for
environment reasons rather than code reasons until the venv is on PATH; confirm with
`./venv/bin/python -m pytest -q` before believing a red pre-flight.

### The one thing worth reading the code for

`pipeline.py:191` returns silently when `should_analyze(message.content)` is false,
and `bot.py:31` requests the **privileged** `message_content` intent. Ungranted
intent means empty content means silent skip means zero API calls — with a bot that
looks entirely healthy. That chain is the leading hypothesis for the thirty-day
zero-traffic mystery (O-01), and the reason this gameplan puts observability first.
Do not let a later phase "fix" the zero traffic before Phase 3 has established the
cause.
